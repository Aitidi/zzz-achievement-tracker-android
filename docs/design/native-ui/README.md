# 简洁风格原生 UI 重设计

分支：`codex/ui-redesign`。技术栈保持 Kotlin / Jetpack Compose。

## 设计方向

完全替换旧版深色、紫色光晕、荧光标签和独立边框卡片。新版使用浅灰背景、白色分组、系统蓝、大标题、低对比度分隔线，强调清晰的阅读层级与简洁的操作流程。

- 成就：总进度 → 搜索 → 全部/未完成 → 筛选/排序 → 分组成就列表。左侧圆形完成按钮与右侧详情入口分开，避免误操作。
- 统计：整体进度环、已完成/待完成计数、连续的分版本进度列表。
- 设置：显示、数据管理、独立的重置区域；紧凑模式使用开关，导入导出整行可点击。
- 所有进度、搜索、筛选、排序、编辑锁定与备份继续使用现有 ViewModel / Room，不改变目录和进度格式。

## 截图与设计核对

本项目为原生 Android 应用，浏览器/IAB/Playwright 不适用。使用 Android API 36 模拟器、ADB、UIAutomator 语义树验证；通过 `screencap` 获取实际界面，再用 `view_image` 检查概念稿与最终截图。

- 标准竖屏：1080 × 2340 px，440 dpi，约 393 × 851 dp，字体缩放 1.0。
- 小屏大字：1080 × 1920 px，480 dpi，360 × 640 dp，字体缩放 1.3。
- 横屏：2340 × 1080 px，440 dpi；验证滚动后后续内容可到达。
- 概念稿为三个并列屏幕，单屏目标约 390 × 844，实际使用最接近的原生模拟器尺寸；系统状态栏、导航键、安全区保留 Android 行为。

| 核对点 | 参考与实测 | 结果 / 处理 |
| --- | --- | --- |
| 配色 | 浅灰底、白分组、系统蓝 | 移除旧紫色、荧光黄和渐变；统一主题与系统栏 |
| 布局 | 大标题、分组列表、底部三标签 | 已保持相同信息层级；长列表真实滚动 |
| 字体 | 标题/正文/元数据层级 | 统一 Typography；跟随系统字重、字号缩放 |
| 容器 / 间距 | 20 dp 分组圆角与内缩分隔线 | 成就合并为连续列表，元数据移到描述下方 |
| 图标 / 状态 | 蓝色选中、圆形勾选、列表箭头 | 使用原生矢量图标；编辑锁与完成状态具有语义说明 |
| 文案 | 成就、统计、设置及其主要标签 | 固定文案对照通过；概念图示例数据替换为真实 804 条、最新 v3.2 |
| 键盘 | 搜索时结果应可见 | 首轮顶部占位过多，改为搜索聚焦时收起标题和总进度 |
| 小屏 / 横屏 | 保持主要操作可到达 | 高度不足 680 dp 使用紧凑标题；宽度超过 500 dp 搜索与分段并排 |
| 长文本 | 不挤压完成按钮与元数据 | 紧凑模式省略，详情弹窗显示完整说明；非紧凑模式增加行数 |

有意保留的差异：使用 Android 系统字体和 Material 矢量图标；保留 Android 系统栏、键盘和文件选择器；统计版本行没有跳转功能，所以未复制概念图上的右箭头；完成数和版本均为真实数据，非概念图示例。以上差异以外，本轮未发现阻塞使用的视觉问题。

## 验证结果

执行 `gradle :app:assembleDebug :app:testDebugUnitTest :app:lintDebug --console=plain` 成功。现有目录数据测试 2 项全部通过。Lint 无错误，仍有现有依赖可升级等非阻塞提示。

模拟器实际交互验证：

1. 勾选「明礁」后总数从 0/804 更新到 1/804；强制退出并重启后保留。
2. 锁定编辑后完成控件 disabled，点击不修改进度；解锁恢复。
3. 点成就文字打开详情，完整说明及“标为已完成/未完成”动作正确。
4. v3.2 + 勘域探境组合筛选得到 2 条；清除后恢复 804 条。
5. 新旧排序切换后首项版本从 v3.2 变为 v1.0，切回正常。
6. 搜索 NEDF 得到 1 条结果；无匹配关键词显示空状态。键盘打开时结果与关闭入口可见。
7. 设置页紧凑开关改变列表行距和文字行数。
8. 导出 JSON 含 804 条、1 条已完成；一次重置只出现 1/5 提示；连续五次重置后为 0/804；导入刚导出的文件应用 804/804 条并恢复 1/804。全部操作仅在独立 debug 包中进行。
9. 三页切换、横屏滚动、窄屏大字号显示正常，未发现 AndroidRuntime 崩溃。

预览安装包使用独立包名 `com.aitidi.zzzachievementtracker.debug`，显示为“ZZZ成就 · UI预览”，可与正式版并存，数据也相互独立。可从正式版导出 JSON，再导入预览版体验。正式发布包名不变。

仅验证上述模拟器环境，未声称完成所有 Android 机型的兼容性测试。没有推送远程或发布正式版本。
