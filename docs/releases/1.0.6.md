# ZZZ成就 1.0.6

适配《绝区零》3.3 版本，新增 18 项成就，成就总数更新至 **822 项**。本次同时带来新版界面和成就筛选改进。

## 界面与使用体验

- 重新设计成就、统计和设置页面，采用浅色背景、分组列表与更清晰的文字层级。
- 分类筛选按「故事 / 城市 / 战术 / 探索」分组，支持跨组多选，并显示各组已选数量。
- 城市分类「布亚斯特」统一显示为「罗斯凯利法」，已有筛选条件自动兼容。
- 完成勾选与详情入口分开，减少误操作；成就详情可查看完整说明。
- 调整搜索键盘弹出、小屏大字号和横屏时的布局。

## 升级说明

- 可使用本页 APK 覆盖安装旧版正式应用；包名和签名证书与 1.0.5 保持一致。
